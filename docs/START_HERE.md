## Documentation Maintenance Rules

Any project change must update documentation.

Rules:

1. Architecture change
   → update ARCHITECTURE.md

2. New project principle
   → update ARCHITECTURE_PRINCIPLES.md

3. Important decision
   → update DECISION_LOG.md

4. Current project state changed
   → update PROJECT_STATUS.md

5. Confirmed statistical finding
   → create or update OUTCOME_REVIEW

6. New hypothesis or research idea
   → update RESEARCH_NOTES.md

7. Roadmap changed
   → update ROADMAP.md

If documentation is not updated, work is considered incomplete.
