# TELEGRAM CONSOLE

Version:
V2.8

Status:
ACTIVE

Purpose:

Telegram is the primary user interface of Crypto Anomaly Monitor.

The goal of the console is not simply to display information.

The goal is to help the researcher and trader make better trading decisions using accumulated research.

---

# Design Principles

Every command must satisfy at least one of the following purposes:

• Monitor system health
• Explain model behaviour
• Compare opportunities
• Support trading decisions
• Summarize research
• Track research progress

If a command satisfies none of these goals, it should not be added.

---

# Console Philosophy

The console should answer five questions.

1.
Is the system healthy?

2.
What is happening in the market?

3.
Why does the model think so?

4.
Should I trade?

5.
What have we learned?

Everything else is secondary.
